## Lab 1: File System Navigation

### Objective

Learn basic file system navigation using the macOS terminal.

### Commands Used

- pwd
- ls
- ls -la

### Steps Performed

1. Used `pwd` to display the current working directory.
2. Used `ls` to list the contents of the current directory.
3. Used `ls -la` to display all files and directories, including hidden files.

### Results

Successfully navigated the file system and viewed files, directories, and permissions.
