## Lab 1: File System Navigation

### Objective

Learn basic file system navigation using the macOS terminal.

### Commands Used

- pwd
- ls
- ls -la
- cd
- mkdir
- rmdir

### Steps Performed

1. Used `pwd` to identify the current working directory.
2. Used `ls` to list the contents of the home directory.
3. Used `ls -la` to display all files and directories, including hidden files and detailed permissions.
4. Used `cd Library` to navigate into the Library directory.
5. Used `mkdir CyberLabs` to create a new directory named CyberLabs.
6. Verified the directory was created by listing directory contents.
7. Used `rmdir CyberLabs` to remove the empty directory.
8. Verified the directory was successfully removed.
9. Navigated between directories using the `cd` command to better understand file system structure.

### Results

Successfully navigated the macOS file system, viewed directory contents and permissions, created and removed directories, and practiced using common terminal commands for file system management.
