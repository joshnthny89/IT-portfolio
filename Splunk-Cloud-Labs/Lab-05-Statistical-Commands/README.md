# 📊 Lab 05 – Statistical Commands

## Objective

Learn how to use Splunk's statistical commands to summarize and analyze large volumes of machine data. This lab introduces commands such as `stats`, `top`, `rare`, and `chart`, demonstrating how raw events can be transformed into meaningful information that supports troubleshooting, system monitoring, and security investigations.

# Lab Walkthrough

## Scenario

After organizing and refining search results in the previous lab, the next step is to summarize the data to identify patterns and trends. Rather than reviewing individual events one at a time, statistical commands provide a high-level view of activity, helping analysts quickly identify unusual behavior, frequently occurring events, and systems generating the most activity.

---

## Step 1 – Search Indexed Events

Started by performing a broad search to retrieve indexed events.

```spl

```

Beginning with a broad search establishes a dataset that can be summarized using statistical commands.

## Step 2 – Count Events by Host

Used the `stats` command to count the number of events generated by each host.

```spl
index=* | stats count by host
```

Summarizing events by host provides a quick overview of which systems are generating the most activity.

## Step 3 – Identify the Most Common Sources

Used the `top` command to display the most frequently occurring event sources.

```spl
index=* | top source
```

This command quickly highlights the data sources contributing the highest number of events.

## Step 4 – Identify Rare Event Sources

Used the `rare` command to locate event sources that appeared infrequently.

