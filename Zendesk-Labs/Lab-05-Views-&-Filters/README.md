# 🎫 Lab 05 – Views & Filters

## Objective

Learn how to use Zendesk Views and Filters to organize support tickets based on predefined criteria. This lab demonstrates how Views improve workflow efficiency by allowing support agents to quickly locate, monitor, and manage groups of tickets requiring attention.

---

## Skills Practiced

- Zendesk Views
- Ticket Filtering
- Ticket Organization
- Workflow Management
- IT Service Management (ITSM)
- Help Desk Operations

---

## Tools Used

- Zendesk Support
- Zendesk Agent Workspace
- Views
- Filters

# Lab Walkthrough

## Step 1 – Navigate to Views

From the Zendesk Agent Workspace, selected **Views** from the left navigation menu.

Views provide organized lists of tickets based on specific conditions, allowing support agents to quickly identify work requiring attention.

## What I Learned

This lab introduced Zendesk Views as a powerful organizational tool for managing support requests. By filtering tickets according to predefined criteria, support agents can quickly locate relevant tickets, prioritize workloads, and improve response efficiency. Understanding how to navigate Views is an essential skill for maintaining an organized and productive help desk environment.
