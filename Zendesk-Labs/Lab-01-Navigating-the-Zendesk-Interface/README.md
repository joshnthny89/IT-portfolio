# 🎫 Lab 01 – Navigating the Zendesk Interface

## Objective

Become familiar with the Zendesk Support interface by exploring the workspace used to manage customer support requests. This lab introduces the primary navigation menus, ticket workspace, and essential features used daily by IT support specialists and help desk technicians.
